# Oculith Draw fonts

These files were copied unchanged from the Oculith app
(`static/fonts/`, commit `7efdf6a1`) for a consistent Oculith desktop
appearance. The Oculith app took them as Latin woff2 subsets from Fontsource.
`styles/oculith-tokens.css` declares them as `--ox-font`, `--ox-font-mono`
and `--ox-font-serif`.

| File | Family | License |
| --- | --- | --- |
| `geist-latin-wght-normal.woff2` | Geist (variable, 100-900), by The Geist Project Authors | SIL OFL 1.1, `OFL-Geist.txt` |
| `geist-mono-latin-wght-normal.woff2` | Geist Mono (variable, 100-900), by The Geist Project Authors | SIL OFL 1.1, `OFL-Geist.txt` |
| `instrument-serif-latin-400-italic.woff2` | Instrument Serif Italic, by The Instrument Serif Project Authors | SIL OFL 1.1, `OFL-InstrumentSerif.txt` |

The complete license texts are in this directory and are bundled with the
desktop app under `notices/fonts/`.
