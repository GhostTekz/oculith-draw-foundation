# Oculith Draw package notices

Tauri copies this directory to `notices/third-party/` in desktop packages. The
application's unchanged root `LICENSE.md` is copied separately to
`notices/Oculith-Draw-LICENSE.md`. Oculith Draw is based on Open PDF Studio by
the OpenAEC Foundation; the repository history and About panel retain that
attribution.

The bundle configuration also copies these existing source notices verbatim:

| Distributed material | Notice in package |
| --- | --- |
| PDFium binary and its included components | `notices/pdfium/LICENSE`, `notices/pdfium/licenses/`, and the binary-distribution notices under `notices/pdfium/{linux-x64,win-x64,win-arm64}/` |
| PDF.js, CMaps, and standard fonts | `notices/pdfjs/` |
| Geist and Geist Mono web fonts | `notices/fonts/OFL-Geist.txt` |
| Instrument Serif web font | `notices/fonts/OFL-InstrumentSerif.txt` |
| Tesseract `tessdata_fast` OCR data | `notices/third-party/tessdata_fast-LICENSE` |
| Noto Sans CJK font used for OCR text | `notices/third-party/noto-cjk-Sans-LICENSE` |
| GEOS 3.14.1, when a desktop build includes the shared libraries | `notices/third-party/GEOS-NOTICE.txt` and `notices/third-party/LGPL-2.1.txt` |

Lucide icon geometry is vendored into the frontend bundle as
`js/solid/data/lucideIcons.js` (generated by `scripts/generate-lucide-icons.mjs`
from lucide-react 1.55.0, the version the Oculith desktop app pins at commit
`7efdf6a1`). Its ISC license, including the MIT notice for icons derived from
Feather, is copied unchanged from that package as `lucide-LICENSE` in this
directory, so it ships as `notices/third-party/lucide-LICENSE`. The fonts
were copied with their OFL texts from the Oculith app's `static/fonts/` at the same
commit.

The OCR notices above were copied without modification from the upstream
[`tessdata_fast` LICENSE](https://github.com/tesseract-ocr/tessdata_fast/blob/main/LICENSE)
and [Noto CJK Sans LICENSE](https://github.com/notofonts/noto-cjk/blob/main/Sans/LICENSE)
on 2026-10-13. The corresponding assets are fetched by `scripts/ocr-runtime.mjs`
using pinned SHA-256 hashes during a desktop build.

`npm-inventory.json` lists the production entries from the checked-in npm lockfile.
Where the installed npm package contains a license or notice file, its text
is copied from that package version under `npm/` (line endings and trailing
whitespace are normalized). A `null` `noticeFile` means the npm
package did not contain such a file; `licenseFromLockfile` reports only the
metadata present in the lockfile and is not a substitute for a license text.
The inventory includes platform-specific optional packages that may not be
present in every desktop bundle. Changes to the dependency lockfile require
review and regeneration of this inventory and its copied notices.

The `@crabnebula/tauri-plugin-drag` 2.1.0 npm archive has no license field or
license file. Its `npm/@crabnebula/tauri-plugin-drag/` directory contains the
upstream repository's `LICENSE.spdx`, `LICENSE_MIT`, and `LICENSE_APACHE-2.0`
from the [`tauri-plugin-drag-v2.1.0` tag](https://github.com/crabnebula-dev/drag-rs/tree/8a0be885a087c076b8127743b217b795e8b4fe9d)
at commit `8a0be885a087c076b8127743b217b795e8b4fe9d`. The npm archive's
`guest-js/index.ts` matches that tag's JavaScript source byte for byte
(SHA-256 `bc2521c0c7b19cd503c69efc108102c58aab02349f1b8409a306c070b5c0dc0a`).
The copied upstream texts have SHA-256 hashes
`6326d64033572a9b5f627ec7a39fd468dcbc6e01ee12fa71a600c66e12e0e411`,
`9e17784d32fbb3ac50c6c543c307d0fbcb16969585cb4cee8839b50e774708f9`,
and `0d542e0c8804e39aa7f37eb00da5a762149dc682d7829451287e11b938e94594`,
respectively. The upstream README describes the repository's licenses as
"MIT or MIT/Apache 2.0 where applicable." The inventory retains null
`licenseFromLockfile` and `noticeFile` values because these texts came from
the tagged upstream source, rather than from the npm archive.

`rust-inventory.json` is a reproducible snapshot of the locked workspace graph's
raw Cargo `license` and `license-file` fields. Regenerate it from the repository
root with `python scripts/rust-license-inventory.py`; verify it with
`python scripts/rust-license-inventory.py --check` (add `--offline` when Cargo
dependencies are already cached). Its `cargoLockSha256` ties the snapshot to
the checked-in lockfile. The inventory includes development, build, and
platform-specific dependencies; it does **not** identify which crates or
native libraries are linked into a particular release binary.

`rust-third-party-notices.txt` bundles root license, notice, and authors texts
from all 778 external crate archives in the locked graph. Identical source
texts are stored once and referenced by SHA-256 from each package; line endings
and trailing whitespace are normalized in the bundle. For 61 archives
without a root license file, it includes the license's standard SPDX text in
an appendix and marks the package section as a fallback. Those standard texts
are pinned under `scripts/rust-spdx-texts/`; they came from the `spdx` 0.13.4
crate's license text collection. The MIT template contains copyright
placeholders, so fallback entries need source and attribution review before
release. `rust-notice-manifest.json` records each included source file's hash,
package identity, fallback IDs, and the lockfile hash. To regenerate and verify:

```
python scripts/rust-license-inventory.py --offline
python scripts/rust-notice-bundle.py --offline
python scripts/rust-license-inventory.py --check --offline
python scripts/rust-notice-bundle.py --check --offline
```

The graph currently has 784 packages: 778 external and six workspace crates.
`pdfium-worker` now declares LGPL-3.0-or-later, matching the application. The
`open-pdf-render` workspace crate declares MIT; its authors should verify that
declaration and a standalone notice before distribution. Forty-seven external
packages still carry legacy slash-form license expressions. The generator
includes standard texts for all alternatives when a crate has no license file;
it does not decide which alternative the distributor chooses. Cargo explains
the metadata in its [manifest reference](https://doc.rust-lang.org/cargo/reference/manifest.html#the-license-and-license-file-fields).

This notice bundle includes optional and platform-specific dependencies, so
each installer may contain more notices than linked crates. Final desktop
packages still need platform-specific inspection for native libraries and
resource placement after installers are built.
